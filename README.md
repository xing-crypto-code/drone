# CF-Drone ESP32 无人机飞控

**基于 ESP32 的开源四旋翼飞控固件 —— 支持手机网页遥控，无需遥控器也能飞。**

本项目是一套运行在 ESP32 上的四旋翼飞行控制器固件，使用 Arduino 框架开发。
它把姿态解算、串级 PID 控制、电机混控、失效保护、网页遥控和 MAVLink 遥测
全部塞进一颗几块钱的 ESP32 里，配合一块简单的四合一 MOS 板就能起飞。

一大特点是**自带网页遥控器**：飞控自己开 WiFi 热点，手机连上后用浏览器打开即可操纵，
不用另外买遥控器和接收机（当然也支持 CRSF/ELRS 和 SBUS 接收机）。

## ✨ 功能特性

### 飞行控制

- **串级 PID 控制**：角度外环 + 角速率内环两级串联，抗扰动能力强、姿态稳
- **姿态估计**：陀螺仪积分 + 加速度计重力修正（Mahony 风格互补滤波），
  引出虚拟陀螺偏置，避免与内环 I 项耦合振荡
- **多种飞行模式**：

  | 模式 | 说明 |
  | --- | --- |
  | `STAB` | 自稳模式，摇杆控制倾角，松杆自动回平 —— **新手用这个** |
  | `ACRO` | 特技模式，摇杆直接控制角速度，松杆不回平，可翻滚 |
  | `RAW` | 手动直通，直接输出力矩，调试用 |
  | `ALTHOLD` | 气压计定高（占位实现，待完善） |
  | `AUTO` | 自动模式（失控保护自动降落时进入） |

- **软件配平**：用 `CTL_TRIM_ROLL` / `CTL_TRIM_PITCH` 在线补偿重心偏移、
  电机推力差异等引起的固定方向漂移，不用改机械结构
- **电机解饱和**：某个电机推力顶到上限时，保持总推力不变、等比例缩减力矩分量，
  避免"一个电机满转、姿态失控"
- **D 项低通滤波 + 积分限幅**：抑制噪声放大和积分饱和
- **可调推力上下限**：`MOT_THR_MIN` / `MOT_THR_MAX`，适配不同动力配置

### 安全保护

| 保护类型 | 触发条件 | 动作 |
| --- | --- | --- |
| 遥控失联 | 超过 `SF_RC_LOSS_TIME`（默认 1 秒）未收到遥控信号 | 平滑下降，10 秒后自动停机 |
| 网页失联 | 超过 8 秒未收到网页控包 | 同上 |
| 电池低电 L1 | 电压 < 3.5V（未解锁/怠速时） | 禁止解锁 + LED 快闪告警 |
| 电池低电 L2 | 电压 < 3.3V（飞行中） | 告警，LED 快闪 |
| 电池低电 L3 | 电压 < 3.0V（飞行中） | 自动降落 |
| 倒置保护 | 机身倾斜 > 134° 持续 1.5 秒 | 立即停机，避免损失扩大 |
| IMU 故障 | IMU 初始化或通信失败 | 禁止解锁 |

另外还支持**未接电池自动识别**（电压 < 0.5V 时忽略所有电压告警）。

### 网页遥控器

- 飞控自建 WiFi 热点（默认 `Drone_WiFi` / 密码 `12345678`），**SSID 和密码都可在线修改**
- 手机/平板浏览器打开 `http://192.168.4.1` 即可操纵，界面自适应响应式
- 摇杆 + 按钮操作，带**解锁/上锁/急停**按钮和飞行模式切换
- 控制发包频率 20Hz，含网络延迟监测
- 内置**网页调试控制台**，可直接在浏览器里敲 CLI 命令、看日志输出
- 支持倒置保护、失联保护、低电告警的前端提示

### 通信与遥测

- **MAVLink**：走 UDP，可被 QGroundControl / Mission Planner 等标准地面站识别，
  显示姿态、电量、遥控通道、电机输出等（仅遥测显示，不用于控制）
- **CRSF / ELRS**：默认遥控协议，420000 波特率，支持遥测回传
- **SBUS**：兼容传统 SBUS 接收机，100000 波特率
- **串口 CLI**：115200 波特率，20+ 条命令，参数在线修改并自动存 Flash

### 调试与调参

- **在线调参**：所有 PID 参数、保护阈值、引脚映射都能用 CLI 随时改，掉电不丢
- **飞行日志**：内存滚动记录 100Hz 的姿态/角速率/目标值/推力，
  用 `log dump` 导出分析（只存内存不写 Flash，避免擦写寿命问题）
- **状态 LED**：待机常灭 / 飞行慢闪 1Hz / 告警快闪 8Hz

## 🔧 硬件支持

| 项目 | 支持情况 |
| --- | --- |
| 主控芯片 | ESP32 / ESP32-S3 / ESP32-C3（自动适配，无需改代码） |
| 姿态传感器 | MPU6500 / MPU9250（SPI 接口） |
| 遥控接收 | CRSF/ELRS（默认）、SBUS |
| 电机输出 | 4 路 LEDC PWM，25kHz / 10bit，可直驱 MOSFET 或接 ESC |
| 电池检测 | ADC 分压采样（默认 43/33 分压比） |
| 状态指示 | 板载 LED |
| 扩展板传感器 | BMP388 / VL53L1X / QMC5883L / PMW3901（可选） |

引脚定义全部集中在 `CF-Drone-main/board_config.h`，按芯片型号条件编译，改硬件只需改这一个文件。

## 🚀 快速上手

### 1. 环境准备

**必须使用 Arduino IDE 2.3.x 及以上版本**（1.8.19 不支持）。

在 Arduino IDE 中安装：

1. **ESP32 开发板核心库** —— 开发板管理器搜索 `esp32`（by Espressif Systems），
   建议使用 **3.3.10** 版本
2. **MAVLink 库** —— 库管理器搜索 `MAVLink`

### 2. 编译烧录

1. 用 Arduino IDE 打开 `CF-Drone-main/CF-Drone.ino`
2. 开发板选择对应型号（如 `ESP32 Dev Module`）
3. 选择正确的串口，点击上传

### 3. 首次使用

1. 上电后打开串口监视器（**115200** 波特率），输入 `help` 查看命令列表
2. 输入 `ca` 按提示完成**加速度计六面校准**（水平/机头朝上/朝下/左/右侧/倒置）
3. 输入 `cr` 校准遥控器行程
4. 手机连接 WiFi 热点 `Drone_WiFi`（密码 `12345678`），浏览器打开 `http://192.168.4.1`
5. 用 `ps` 检查姿态是否正常，`imu` 检查传感器数据

> ⚠️ **首次试飞前务必拆掉桨叶！** 用 `mfr` / `mfl` / `mrr` / `mrl` 逐个确认电机转向和对应位置。

## 🎮 常用命令

```text
help                 显示全部命令
p                    查看所有参数
p <参数名>            查看单个参数
p <参数名> <值>       修改参数（立刻生效并自动存 Flash）
preset               重置参数为默认值
ca                   校准加速度计（六面校准）
cr                   校准遥控器
ps / psq             显示姿态角 / 姿态四元数
imu                  显示 IMU 原始数据
rc                   显示遥控通道数据
mot                  显示电机输出
sys                  显示系统信息（芯片型号、内存等）
log / log dump       查看 / 导出飞行日志
arm / disarm         解锁 / 上锁
raw/stab/acro/auto   切换飞行模式
ap <ssid> <密码>      配置 WiFi 热点名称和密码
sta <ssid> <密码>     配置为连接路由器模式
reboot / reset       重启 / 恢复出厂
```

**解锁手势**（防误触设计）：油门摇杆拉到最低 **且** 偏航摇杆推到最右；
上锁则是最低油门 + 偏航最左。低电或 IMU 故障时会拒绝解锁。

## 📊 参数速查

| 前缀 | 含义 |
| --- | --- |
| `CTL_*_RATE_*` | 内环（角速率环）PID 参数 |
| `CTL_R_*` / `CTL_P_*` / `CTL_Y_*` | 外环（角度环）PID 参数 |
| `CTL_TRIM_*` | 软件配平（补偿固定方向漂移） |
| `CTL_FLT_MODE_*` | 遥控三挡开关对应的飞行模式 |
| `EST_LVL_*` | 姿态水平修正参数 |
| `MOT_*` | 电机引脚、PWM 频率、推力上下限 |
| `SF_*` | 失效保护阈值 |
| `RC_*` | 遥控协议、引脚、波特率 |
| `WIFI_*` | WiFi SSID / 密码 |

改 PID 的建议：先调内环（`RATE`）再调外环，每次只改一个参数、小步长试飞。
